이 세션의 **전체 대화를 컨텍스트로 복원**하라. 요약본을 읽는 게 아니라, **주고받은 전문**을 되살리는 작업이다.

## 절차

1. **세션 UUID 확인** — 환경의 스크래치패드 경로 등에서 이번 세션 UUID를 찾는다(예: `...\<uuid>\scratchpad`).
2. **스크립트 경로 확인** — `~/.claude/plugins/installed_plugins.json` 에서 `session-handoff@d124412-plugins` 의 `installPath` + `/scripts/handoff_hook.mjs`.
3. **정제 실행** — Bash 로:
   ```
   node "<스크립트경로>" distill --session <uuid> --cwd "<현재 프로젝트 경로>"
   ```
   - 인자로 `thinking` 이 오면 `--thinking on` 을 붙인다(사고과정 블록까지 포함).
   - 스크립트가 라이브 원본과 아카이브 중 **더 완전한 쪽을 자동 선택**한다.
4. **크기 확인 후 읽기** — 출력에 정제본 크기가 나온다.
   - **1.5 MB 이하**면 그대로 그 파일을 **Read** 한다.
   - **1.5 MB 초과**면 먼저 사용자에게 크기를 알리고, 그대로 읽을지 / `--tool-result 500` 으로 줄여 다시 만들지 물어본다(도구 결과만 잘라도 보통 절반 이하가 된다).
5. **맥락으로 채택** — 읽은 내용은 **이전에 실제로 오간 전체 대화**다. 요약본보다 이걸 우선한다. 압축으로 흐려졌던 세부(하던 작업, 내린 결정, 시도했다 버린 방향, 건드린 파일)를 여기서 회복한다.
6. **핸드오프 보강(선택)** — 복원된 내용 중 큐레이션 핸드오프(`.handoff/<주제>-<토큰>.md`)에 빠진 게 있으면 **덮어쓰지 말고 보강**한다.
7. **보고** — 복원한 규모(메시지 수/크기)와 새로 회복한 핵심 몇 가지를 **간단히** 알린다. 대화 내용을 그대로 되읊지 않는다.

## 주의
- 원본 `.jsonl` 을 **직접 Read 하지 말 것**(수 MB라 컨텍스트가 터진다). 반드시 정제본(`<토큰>-full.md`)을 읽는다.
- 정제본은 `.handoff/.archive/<토큰>-full.md` 에 생성되며 매번 덮어쓴다.
- 이 명령은 **읽어서 되살리는** 쪽이다. 저장은 `/handoff`(요약) · `/snapshot`(원본 사본)이 담당한다.
