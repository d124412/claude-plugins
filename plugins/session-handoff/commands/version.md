이 플러그인의 버전 상태를 확인하라.

1. **스크립트 경로 확인** — `~/.claude/plugins/installed_plugins.json` 에서 `session-handoff@d124412-plugins` 의 `installPath` + `/scripts/handoff_hook.mjs`.
2. **실행** — Bash 로: `node "<스크립트경로>" version`
   - 출력에 **실행 중(스크립트)** / **설치됨(디스크)** / **마켓 최신(원격)** 세 값이 나온다.
3. **"로드된 버전" 확인** — 이 세션이 시작될 때 훅이 주입한 **`session-handoff vX.Y.Z 로드됨`** 줄을 컨텍스트에서 찾는다. 그게 **이 세션이 실제로 로드한 버전**이다(없으면 "확인 불가"로 처리).
4. **비교해서 결론을 낸다** — 표로 간단히 보여주고 판정한다:

| 항목 | 의미 |
|---|---|
| 로드됨(이 세션) | 세션 시작 시 로드된 **명령문** 버전 |
| 설치됨(디스크) | `installed_plugins.json` 기록 |
| 마켓 최신(원격) | 저장소 `origin/main` 의 최신 |

판정 규칙:
- 셋 다 같으면 → **최신 상태입니다.**
- **로드됨 ≠ 설치됨** → **Claude Code 재시작이 필요합니다.** (명령문은 세션 시작 시 1회만 로드되므로, 업데이트해도 재시작 전엔 구버전 지시문이 돈다)
- **설치됨 ≠ 마켓 최신** → **`/update-plugin` 을 실행하세요.**

결과는 표 + 판정 한두 줄로 **간단히** 보고한다.
