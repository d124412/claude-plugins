지금 이 세션의 인수인계(handoff)를 최신화하라. 세션 인수인계 규칙(이 플러그인의 RULES.md)에 따라 진행한다:

1. **내 세션식별자 확인** — 세션 시작 훅이 주입한 `<주제슬러그>-<토큰>` 형식을 쓴다. 모르면 환경(스크래치패드 경로 등)의 세션 UUID 앞 6자리를 토큰으로 삼는다.
2. **내 세션 폴더 확보** — 세션 하나가 폴더 하나를 소유한다: `.handoff/<세션식별자>/`
   - `.handoff/` 에서 이름이 `<토큰>` 이거나 `-<토큰>` 으로 끝나는 폴더를 찾는다. 있으면 **그게 내 폴더다**(새로 만들지 말 것).
   - 찾은 폴더 이름이 **토큰뿐**이라면(예: `ba2968`), 훅이 주제를 모른 채 먼저 만든 것이다 → **`<주제슬러그>-<토큰>` 으로 이름을 바꾼다.** 안에 있는 파일은 그대로 둔다.
   - 없으면 `.handoff/<주제슬러그>-<토큰>/` 을 만든다. `.handoff/INDEX.md` 도 없으면 만든다.
3. **`handoff.md` 갱신** — 내 폴더 안의 `handoff.md` 에 현재 시각(KST)과 함께 아래 섹션을 채운다:
   - 프로젝트 개요 / 현재 상태(최종 갱신 시각 포함) / 다음에 할 일 / 중요 결정·맥락 / 미해결 이슈
   - 코드를 통째로 복붙하지 말고 "어디에 무엇이 있고 왜 그런지"를 남겨, 다음 세션이 이 파일만 읽고 이어갈 수 있게 한다.
   - 이미 내용이 있으면 **덮어쓰지 말고 보강**한다.
4. **INDEX 갱신** — `INDEX.md` 에서 **자기 줄만** 갱신한다: `세션식별자 | 최종 갱신 시각 | 상태 | 주제`. 다른 줄·다른 세션 폴더는 건드리지 않는다.
5. **인자 반영** — 인자로 `완료`/`중단`/`진행중` 이 오면 INDEX 자기 줄의 상태에 반영한다(기본: `진행중`). 이 라벨은 **표시용**이라 이후 동작(자동 백업·넛지)을 바꾸지 않는다.
6. 끝나면 `handoff 갱신 완료 (<세션식별자>)` 라고만 알린다.

## 내 세션 폴더 구조 (참고)

```
.handoff/<주제슬러그>-<토큰>/
├── handoff.md          ← 이 명령이 쓰는 큐레이션 요약 (사람이 읽는 것)
├── fallback.md         ← 압축 직전 훅이 만든 무LLM 뼈대 (자동)
├── restore-pending     ← 복원 마커 (자동, 소비 즉시 삭제)
├── archive/            ← 대화 원본 (compact-*.jsonl 최신 5 · snap-*.jsonl 최신 3)
└── restore/            ← /restore 정제본 (restore-full/normal/lite.md)
```

- **`handoff.md` 외에는 이 명령이 건드리지 않는다.** 나머지는 훅과 `/restore` 가 관리한다.
- 다른 세션 폴더는 **읽기(겹침 확인)만** 하고 쓰지 않는다. 이 파일 단위 소유권이 동시 세션 충돌을 원천 차단한다.
