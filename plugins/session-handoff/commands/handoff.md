---
description: 현재 세션의 handoff 파일과 .handoff/INDEX.md 를 지금 최신화한다
argument-hint: "[완료|중단|진행중]"
---

지금 이 세션의 인수인계(handoff)를 최신화하라. 세션 인수인계 규칙(이 플러그인의 RULES.md)에 따라 진행한다:

1. **내 세션식별자 확인** — 세션 시작 훅이 주입한 `<주제슬러그>-<토큰>` 형식을 쓴다. 모르면 환경(스크래치패드 경로 등)의 세션 UUID 앞 6자리를 토큰으로 삼는다.
2. **파일 확보** — `.handoff/INDEX.md` 가 없으면 만든다. 이 세션이 소유한 `.handoff/<세션식별자>.md` 가 없으면 만든다.
3. **세션 파일 갱신** — 현재 시각(KST)과 함께 아래 섹션을 채운다:
   - 프로젝트 개요 / 현재 상태(최종 갱신 시각 포함) / 다음에 할 일 / 중요 결정·맥락 / 미해결 이슈
   - 코드를 통째로 복붙하지 말고 "어디에 무엇이 있고 왜 그런지"를 남겨, 다음 세션이 이 파일만 읽고 이어갈 수 있게 한다.
4. **INDEX 갱신** — `INDEX.md` 에서 **자기 줄만** 갱신한다: `세션식별자 | 최종 갱신 시각 | 상태 | 주제`. 다른 줄·다른 세션 파일은 건드리지 않는다.
5. **인자 반영** — 인자로 `완료`/`중단`/`진행중` 이 오면 INDEX 자기 줄의 상태에 반영한다(기본: `진행중`).
6. 끝나면 `handoff 갱신 완료 (<세션식별자>)` 라고만 알린다.
